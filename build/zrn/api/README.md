## 1. Обзор архитектуры ZRN

Приложения ZRN представляют собой плоские бинарные исполняемые файлы (flat binaries), выполняемые в едином адресном пространстве операционной системы Zareboon.

* **Адрес загрузки:** `0x60000` (определен в `zrn.ld` и загрузчике ядра `loader.c`).
* **Максимальный размер программы:** `0x3F000` байт (~252 КБ).
* **Секция точки входа:** `.text.entry` (макрос `ZRN_ENTRY`).
* **Механизм системных вызовов:** 
  Ядро при запуске приложения сохраняет указатель на таблицу системных вызовов по фиксированному адресу `0x50000`, а также передает его в регистре `EAX`. Заголовок `zrn_syscall.h` определяет макрос:
  ```c
  #define SYSCALL_TABLE (*((void***)0x50000))
  ```
  Функции API вызывают системные сервисы ядра через разыменование соответствующих индексов этой таблицы.

## 2. Структура проекта и сборка (zake)

Сборка приложений осуществляется утилитой `zake`.

### Конфигурация проекта (`zrn.conf`)
В корне каталога приложения размещается файл `zrn.conf`, указывающий версию API:
```ini
api-version=1
```

### Типичная структура приложения:
```text
my_project/
├── zrn.conf           # Версия используемого API (api-version=1)
├── inc/               # Собственные заголовочные файлы проекта
│   └── my_header.h
└── src/               # Исходные коды проекта
    └── main.c
```

`zake` автоматически подключает заголовочные файлы из `api/api_1/inc` и компилирует исходные файлы библиотеки из `api/api_1/src` вместе с кодом вашего приложения.

## 3. Системные вызовы (`zrn_syscall.h`)

Ядро Zareboon предоставляет следующие номера системных вызовов (`enum`):

| Индекс | Константа | Назначение | Прототип |
|---|---|---|---|
| `0` | `SYS_CLEAR` | Очистка текстового экрана/терминала | `void (*)(void)` |
| `1` | `SYS_SLEEP` | Задержка выполнения (в миллисекундах) | `void (*)(const uint32_t ms)` |
| `2` | `SYS_GET_TIME` | Чтение системного времени RTC | `void (*)(struct time_now* t)` |
| `3` | `SYS_DISPLAY_OPEN` | Переключение в графический видеорежим (VBE) | `bool (*)(uint32_t width, uint32_t height)` |
| `4` | `SYS_DISPLAY_PIXEL`| Установка цвета пикселя | `void (*)(uint32_t x, uint32_t y, uint32_t color)` |
| `5` | `SYS_DISPLAY_PRESENT` | Вывод кадрового буфера на экран | `void (*)(void)` |
| `6` | `SYS_GETCH` | Блокирующее чтение символа с клавиатуры | `char (*)(void)` |
| `7` | `SYS_GET_FONT` | Получение битовой маски растрового шрифта (8x8) | `const uint8_t* (*)(uint8_t c)` |
| `8` | `SYS_DISPLAY_FILL` | Аппаратная/буферизованная заливка прямоугольника | `void (*)(uint32_t x, uint32_t y, uint32_t w, uint32_t h, uint32_t color)` |
| `9` | `SYS_DISPLAY_CLOSE`| Закрытие видеорежима, возврат в текстовый режим | `bool (*)(void)` |
| `10` | `SYS_MKDIR` | Создание директории в файловой системе FAT | `void (*)(uint8_t* name)` |
| `11` | `SYS_RMDIR` | Удаление директории | `void (*)(uint8_t* name)` |
| `12` | `SYS_PUTC` | Вывод цветного символа в текстовом режиме | `void (*)(uint8_t ch, uint32_t color)` |
| `13` | `SYS_CREATE_FILE` | Создание пустого файла | `void (*)(const uint8_t* name)` |
| `14` | `SYS_WRITE_FILE` | Запись данных в файл | `void (*)(const uint8_t* name, const uint8_t* data, uint32_t size)` |
| `15` | `SYS_READ_FILE` | Чтение данных из файла | `int32_t (*)(const uint8_t* name, uint8_t* buffer, uint32_t size)` |
| `16` | `SYS_ARGS` | Получение указателя на строку аргументов запуска | `const uint8_t* (*)(void)` |

## 4. Справочник по модулям API

### Входная точка: `zrn.h`

Определяет атрибут для функции входа `main`:
```c
#define ZRN_ENTRY __attribute__((section(".text.entry")))
```
Гарантирует размещение кода `main` по начальному адресу `0x60000`.

---

### Стандартный ввод/вывод: `stdio.h`

#### `void print(const char* format, ...);`
Универсальная форматированная печать в консоль.
* Автоматически распознает активный режим:
  - Если активен графический режим (`gfx_is_open() == true`), выводит символы через `gfx_putc`, затем отрисовывает курсор (`cursor_draw()`) и выполняет флип буфера (`gfx_present()`).
  - Если графический режим не активен, выводит символы в текстовую консоль через `term_putc`.
* **Поддерживаемые спецификаторы формата:**
  - `%s`: вывод строки (`const char*`). Если передан `NULL`, печатается `(null)`.
  - `%c`: вывод отдельного символа (`char`).
  - `%C`: **динамическая смена цвета текста**! Принимает аргумент типа `uint32_t` (RGB цвет). Все последующие символы строки будут выводиться этим цветом.
  - `%d`, `%i`: знаковое целое (`int`).
  - `%u`: беззнаковое 32-битное целое (`uint32_t`).
  - `%x`: шестнадцатеричное число строчными буквами (`0-9`, `a-f`).
  - `%X`: шестнадцатеричное число заглавными буквами (`0-9`, `A-F`).
  - `%%`: вывод символа `%`.
* **Флаги и форматирование:**
  - `-`: выравнивание по левому краю (например, `%-15s`).
  - `0`: заполнение ведущими нулями (например, `%04x`, `%02d`).
  - Числовая ширина поля (например, `%8u`).

---

### Текстовый терминал: `term.h`

Модуль прямого вывода в текстовую консоль операционной системы (активен, если графический режим выключен).

* `void term_putc(char ch, uint32_t color);`  
  Вывод одного символа заданного цвета.
* `void term_write(const char* text, uint32_t color);`  
  Вывод нуль-терминированной строки заданного цвета.
* `void term_clear(void);`  
  Очистка текстового экрана.

---

### Графическая подсистема: `gfx.h` и `video.h`

Модуль для создания графических интерфейсов и игр с поддержкой двойной буферизации.

#### Макросы цветов:
* `gfx_rgb(r, g, b)` (`gfx.h`): формирует цвет в формате `0x00RRGGBB`.
* `rgb(r, g, b)` (`video.h`): формирует цвет в формате `0xFFRRGGBB` (с альфа-каналом 255).

#### Управление дисплеем:
* `bool gfx_open(uint32_t width, uint32_t height);`  
  Инициализирует графический видеорежим заданного разрешения (например, `1024, 768`). Возвращает `true` при успешном открытии.
* `bool gfx_close(void);`  
  Закрывает графический режим и восстанавливает текстовый режим.
* `bool gfx_is_open(void);`  
  Возвращает `true`, если графический режим открыт.
* `uint32_t gfx_width(void);`  
  Возвращает текущую ширину графического экрана в пикселях.
* `uint32_t gfx_height(void);`  
  Возвращает текущую высоту графического экрана в пикселях.
* `void gfx_present(void);`  
  Копирует содержимое закадрового буфера на физический экран.

#### Примитивы рисования:
* `void gfx_pixel(uint32_t x, uint32_t y, uint32_t color);`  
  Рисует одиночный пиксель по координатам `(x, y)`.
* `void gfx_fill(uint32_t x, uint32_t y, uint32_t width, uint32_t height, uint32_t color);`  
  Заливает прямоугольную область размером `width × height` с левым верхним углом в `(x, y)`.
* `void gfx_clear(uint32_t color);`  
  Полностью очищает экран указанным цветом, сбрасывает курсор в `(0, 0)` и сразу вызывает `gfx_present()`.
* `void gfx_glyph(uint32_t x, uint32_t y, uint8_t ch, uint32_t color);`  
  Низкоуровневая отрисовка символа `ch` шрифтом 8x8 с учетом текущего масштаба (`font_scale()`) по пиксельным координатам `(x, y)`.
* `void gfx_putc(uint8_t ch, uint32_t color);`  
  Печать символа в графическом режиме на текущей позиции курсора. Обрабатывает:
  - `\n`: переход на новую строку.
  - `\t`: сдвиг курсора на 4 символа вправо.
  - Автоматический перенос строк при достижении правого края экрана.
  - Циклический возврат наверх при заполнении экрана по высоте.

---

### Шрифты: `font.h`

Управление встроенным растровым шрифтом ядра (базовый размер символа 8x8 пикселей).

* `#define FONT_SIZE 8` — базовый размер глифа в пикселях.
* `uint8_t font_scale(void);`  
  Возвращает текущий коэффициент масштабирования шрифта (по умолчанию: `2`).
* `void font_set_scale(uint8_t scale);`  
  Устанавливает масштаб шрифта (`1` — 8x8 px, `2` — 16x16 px и т.д.). Значение `0` игнорируется.
* `uint32_t font_cell(void);`  
  Возвращает эффективный размер ячейки символа в пикселях: `FONT_SIZE * scale`.
* `const uint8_t* font_glyph(uint8_t ch);`  
  Возвращает указатель на массив из 8 байт (битовую маску) символа `ch`.

---

### Текстовый курсор: `cursor.h`

Управление положением и отображением текстового курсора в графическом режиме.

* `#define CURSOR_MARGIN 2` — отступ курсора от края экрана (в символьных ячейках).
* `void cursor_set(int16_t col, int16_t row);`  
  Устанавливает курсор в указанную колонку (`col`) и строку (`row`).
* `void cursor_move(int16_t dcol, int16_t drow);`  
  Относительное смещение курсора на `dcol` колонок и `drow` строк.
* `int16_t cursor_col(void);`  
  Текущая колонка курсора.
* `int16_t cursor_row(void);`  
  Текущая строка курсора.
* `int32_t cursor_pixel_x(void);`  
  Координата X курсора в пикселях: `col * font_cell()`.
* `int32_t cursor_pixel_y(void);`  
  Координата Y курсора в пикселях: `row * font_cell()`.
* `void cursor_newline(void);`  
  Перевод строки: устанавливает `col = 0`, увеличивает `row` на 1.
* `void cursor_draw(void);`  
  Отрисовывает курсор в виде сплошного белого прямоугольника на текущей позиции.
* `void cursor_erase(void);`  
  Стирает ранее нарисованный курсор (закрашивает черным цветом).
* `void cursor_show(bool visible);`  
  Включает или выключает отображение курсора при выводе текста.

---

### Клавиатура: `keyboard.h`

* `char getch(void);`  
  Синхронно ожидает нажатия клавиши пользователем и возвращает её ASCII-код.

### Время и таймеры: `time.h`

Работа со временем RTC и программными паузами.

```c
struct time_now {
    uint8_t seconds;
    uint8_t minutes;
    uint8_t hours;
};
```

* `void sleep(uint32_t ms);`  
  Блокирующая пауза выполнения программы на `ms` миллисекунд.
* `void get_time(struct time_now* t);`  
  Заполняет структуру `time_now` текущими значениями часов, минут и секунд реального времени.
* `void print_format_time(void);`  
  Форматированный вывод текущего времени в виде `HH:MM:SS`.

---

### Аргументы командной строки: `args.h`

Обеспечивает парсинг строки параметров, переданных программе при запуске из шелла. Максимальная длина строки — 256 байт, до 16 аргументов.

* `uint32_t args_count(void);`  
  Возвращает количество переданных аргументов.
* `const char* args_at(uint32_t index);`  
  Возвращает указатель на `index`-й аргумент (0-индексация). Если индекс больше или равен `args_count()`, возвращает `0` (`NULL`).
* `const char* args_line(void);`  
  Возвращает исходную полную строку аргументов без разбиения на токены.

---

### Файловая система: `system.h`

Работа с директориями и файлами на системном носителе:

* `void make_directory(const uint8_t* name);`  
  Создать каталог с именем `name`.
* `void remove_directory(const uint8_t* name);`  
  Удалить каталог с именем `name`.
* `void create_file(const uint8_t* name);`  
  Создать новый пустой файл `name`.
* `void write_file(const uint8_t* name, const uint8_t* data, uint32_t size);`  
  Записать массив байт `data` длиной `size` в файл `name`.
* `int32_t read_file(const uint8_t* name, uint8_t* buffer, uint32_t size);`  
  Прочитать до `size` байт из файла `name` в буфер `buffer`. Возвращает фактическое число прочитанных байт.

---

### Математика и тригонометрия: `math.h`

Быстрые тригонометрические функции на основе предрассчитанных таблиц (LUT 360 значений):

* `float cos(int deg);`  
  Косинус угла `deg` в градусах. Корректно обрабатывает отрицательные и произвольные углы через нормализацию по модулю 360.
* `float sin(int deg);`  
  Синус угла `deg` в градусах (`cos(deg - 90)`).

---

### Стандартные утилиты: `stdlib.h` и `string.h`

* `int abs(int num);` (`stdlib.h`) — модуль целого числа.
* `void memcpy(void* dest, const void* src, size_t n);` (`string.h`) — побайтовое копирование области памяти.
* `uint16_t strlen(const char* c);` (`string.h`) — длина нуль-терминированной строки.

---

### Базовые типы

* **`stdint.h`**: точные целочисленные типы (`int8_t`, `uint8_t`, `int16_t`, `uint16_t`, `int32_t`, `uint32_t`, `int64_t`, `uint64_t`), а также константа `NULL`.
* **`stdbool.h`**: определение типа `bool`, значений `true` (1) и `false` (0).
* **`stddef.h`**: определение типа `size_t` (`uint32_t`).
* **`stdarg.h`**: макросы для работы с переменным числом аргументов: `va_list`, `va_start`, `va_arg`, `va_end`.

## 5. Примеры разработки приложений

### Пример 1: Консольное приложение («Hello World» с цветным выводом)

```c
#include "zrn.h"
#include "stdio.h"
#include "gfx.h"

ZRN_ENTRY
void main(void) {
    print("%CПривет, %CZareboon OS%C!\n", 
          gfx_rgb(200, 200, 200), 
          gfx_rgb(255, 200, 0), 
          gfx_rgb(200, 200, 200));

    print("Число в hex: %C0x%08X%C\n", 
          gfx_rgb(100, 255, 100), 
          0xCAFEBABE, 
          gfx_rgb(255, 255, 255));
}
```

### Пример 2: Обработка аргументов командной строки

```c
#include "zrn.h"
#include "stdio.h"
#include "args.h"

ZRN_ENTRY
void main(void) {
    uint32_t total = args_count();
    print("Всего аргументов: %u\n", total);
    print("Полная строка: \"%s\"\n", args_line());

    for (uint32_t i = 0; i < total; i++) {
        print("  arg[%u]: %s\n", i, args_at(i));
    }
}
```

### Пример 3: Графическое приложение с анимацией и вводом

```c
#include "zrn.h"
#include "gfx.h"
#include "keyboard.h"
#include "time.h"
#include "math.h"
#include "stdio.h"

ZRN_ENTRY
void main(void) {
    if (!gfx_open(1024, 768)) {
        print("Ошибка: не удалось инициализировать графический режим.\n");
        return;
    }

    uint32_t cx = gfx_width() / 2;
    uint32_t cy = gfx_height() / 2;
    int angle = 0;

    gfx_clear(gfx_rgb(20, 20, 30));

    for (int i = 0; i < 180; i++) {
        gfx_clear(gfx_rgb(20, 20, 30));

        // Вычисляем координаты вращающегося объекта
        int x = (int)cx + (int)(cos(angle) * 150.0f);
        int y = (int)cy + (int)(sin(angle) * 150.0f);

        // Рисуем рамку и вращающийся квадрат
        gfx_fill(x - 20, y - 20, 40, 40, gfx_rgb(255, 80, 80));

        print("%CНажмите любую клавишу для выхода. Кадр: %d", gfx_rgb(255, 255, 255), i);

        sleep(16); // ~60 FPS
        angle = (angle + 4) % 360;
    }

    gfx_close();
}
```

### Пример 4: Работа с файловой системой

```c
#include "zrn.h"
#include "system.h"
#include "stdio.h"
#include "string.h"

ZRN_ENTRY
void main(void) {
    const char* filename = "hello.txt";
    const char* text = "Hello from Zareboon API!";

    // Создание и запись файла
    create_file((const uint8_t*)filename);
    write_file((const uint8_t*)filename, (const uint8_t*)text, strlen(text));
    print("Файл %s успешно записан!\n", filename);

    // Чтение содержимого обратно
    uint8_t buffer[64];
    memcpy(buffer, 0, sizeof(buffer));
    int32_t bytes_read = read_file((const uint8_t*)filename, buffer, sizeof(buffer) - 1);

    if (bytes_read > 0) {
        buffer[bytes_read] = '\0';
```
